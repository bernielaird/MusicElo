# AlbumElo
## General Info
A Django based website for uploading and ranking albums/songs
## Technologies
Project is created with
* Python 3.11
* Django
* HTML
* CSS
*JS
## Getting Started
make a .env in root with:
* SECRET_KEY
* DEBUG
* ALLOWED_HOSTS = 127.0.0.1
* SPOTIPY_CLIENT_ID=
* SPOTIPY_CLIENT_SECRET=
* SPOTIPY_REDIRECT_URI=http://127.0.0.1:8000/callback/
